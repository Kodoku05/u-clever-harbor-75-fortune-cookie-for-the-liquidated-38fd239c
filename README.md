A deterministic program that writes one fortune cookie line of at most 20 words
for a liquidated crypto trader to `/output/entry.txt`. Uses only the Node.js
standard library and requires no network access.

## Run it

With Node.js 22 or newer:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, the output directory defaults to `/output`.
Invalid fortunes or filesystem failures produce an error and a nonzero exit.
